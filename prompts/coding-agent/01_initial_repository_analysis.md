# Coding Agent: Initial Repository Analysis

Prime your coding agent to inspect an existing codebase and prepare it for Agent Task Relay onboarding.

---

```markdown
You are the local coding agent. Please perform an initial assessment of this codebase before configuring Agent Task Relay:

1. Identify the project type, programming language(s), package manager, and framework.
2. Locate existing test suites and the command used to execute them (e.g., `pytest`, `npm test`, `cargo test`).
3. Verify that Git is initialized and check the current branch and repository status.
4. Check if `.gitignore` exists and whether any sensitive files (credentials, `.env`, tokens) are untracked or tracked.
5. Provide a concise summary of the workspace architecture and report readiness for Agent Task Relay setup.
```
